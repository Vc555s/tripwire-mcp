Regression guard for people who build with AI

Tripwire

Describe what must keep working. Tripwire checks it in a real browser after every change, and tells you before a customer does.

Add to Cursor Download

Free and open source. Runs on your own computer. Needs Node.js 18 or newer and Google Chrome.

Up and running in three steps

  1. Press Add to Cursor and confirm. Cursor installs Tripwire for you. There is nothing to configure and no key to enter.
  2. In the Cursor chat, type: Set up Tripwire for https://my-site.com. Tripwire looks at your site and suggests what is worth guarding.
  3. Say what must never break, in your own words: If I use the code WELCOME10, the total should be €13.05. From then on, ask Did I break anything? after any change.
Using another editor, or prefer to set it up by hand?

How it works

    

      

        
01 · SAY IT

        
A promise in plain words

        
You write a sentence about what must keep working. Your editor's AI turns it into browser steps. There is no test code to write.

      

      

        
02 · CHECK IT

        
Checked in a real browser

        
After every change, the coding agent runs your promises against the new version and compares it with the last good one.

      

      

        
03 · KNOW

        
One verdict, with proof

        
SAFECHANGEDBROKEN
With a screenshot, a report, and a GitHub issue linked to the change that caused it.

      

    

  


  

    
What it catches

    

      BROKEN · Discount code WELCOME10 takes 10% off

      expected “€13.05”, showed “€14.49” · the page still said “10% off applied”
    

    
An example from the demo shop, where a tidy-up of one line changed the price. Nothing crashed and no error appeared. The bug is planted for the demo; the check that catches it is the real one.
